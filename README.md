# TV Pictures

A simple picture picker for LG and Samsung TV web browsers.

**Open on the TV:** https://cmarklcs.github.io/tv-pictures/

- Arrow keys to move, **OK** to show a picture full-screen
- **Left/Right** flips through pictures, **Back** returns to the grid

## Adding pictures (staff)

Drop pictures into the shared **TV Pictures** folder in Google Drive, from a computer or phone.
They appear on the TV by themselves within a minute or two. No need to reload the page.

- Pictures are shown in alphabetical order. To choose the order, start file names with
  numbers like `01 Welcome.jpg`, `02 Lunch menu.jpg`. The numbers aren't shown on the TV.
- Any picture type works, including iPhone photos.
- Everything in the folder can be seen by anyone with the TV link, so no private or student photos.

## Adding a video file (staff)

Drop an **MP4** into the **TV Pictures** folder, the same way as a picture. On the TV it shows
with a ▶ Video badge, and when picked it plays full screen **on a loop** until Back is pressed.

- The folder's script sets each video to "Anyone with the link can view" so TVs can stream it.
  Pictures stay private. If a video says it couldn't be shared, its sharing is locked:
  open it in Drive, choose **Share → General access → Anyone with the link**.
- MP4 files from phones, Canva and most editors work. Smaller files start faster.
- The preview picture can take a few minutes to appear after uploading.

## Adding a YouTube video (staff)

1. Open the **TV Pictures** folder in Google Drive and click **New → Google Docs**.
2. Give the doc the name you want shown on the TV, for example `Homecoming video`.
3. Paste the YouTube link into the doc. That's it — it appears on the TV with a ▶ Video badge.

On the TV, **OK** pauses and plays, **Left/Right** moves on, and **Back** returns to the grid.
Some YouTube videos don't allow playing on other sites; those show a YouTube message instead.

## Setting it up

See [SETUP.md](SETUP.md) to connect the TV page to the Drive folder (one time, about 5 minutes).
Until that's done, the page shows the sample pictures in this repository's `pictures` folder.
